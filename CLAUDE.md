## AI Codex

Index files in `ai-codex/` are regenerated on session start and every commit.

| File | Contents |
|------|----------|
| `ai-codex/START.md` | Session orientation: recent changes, tasks, codex index |
| `ai-codex/automation.md` | Generated files, hook-protected ops, project identity |
| `ai-codex/manifest.md` | Comprehensive per-file reference |
| `ai-codex/structure.md` | Project layout, key files, dependency edges |
| `ai-codex/summaries.md` | File content summaries and key concepts |
| `ai-codex/symbols.md` | Reverse index by symbol name |

Read `ai-codex/START.md` first at session start and after `/clear`. Read other files as needed for the current task.
